Device configuration for Xiaomi Mi 11X Pro / Mi 11i / Redmi K40 Pro+
=====================================================================

The Xiaomi Mi 11X Pro / Mi 11i / Redmi K40 Pro+ (codenamed _"haydn"_) is a flagship smartphone from Xiaomi.

It was released in April 2021.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Octa-core (1x2.84 GHz Cortex-X1 & 3x2.42 GHz Cortex-A78 & 4x1.80 GHz Cortex-A55)
Chipset | Qualcomm SM8350 Snapdragon 888 5G (5 nm)
GPU     | Adreno 660
Memory  | 8/12 GB
Storage | 128/256 GB, UFS 3.1
Shipped Android Version | 11
Battery | Li-Po 4520 mAh, non-removable
Display | 1080 x 2400 pixels, 6.67 inches, Super AMOLED, 120Hz, HDR10+ (~395 ppi density)
Camera  | 108 MP (wide), 8 MP (ultrawide), 5 MP (telephoto macro), 20 MP (front)
